# C# Coding Standards

- Use PascalCase for classes, methods and public properties.
- Use camelCase for local variables and private fields.
- Use async/await for IO operations.
- Avoid static classes except for pure helpers.
- Avoid "God" classes and methods with too many responsibilities.
- Prefer constructor injection for dependencies.
- Use guard clauses for argument validation.
- Throw specific domain exceptions when business rules are violated.
- Always include XML or summary comments on public classes and methods when generating new code.
