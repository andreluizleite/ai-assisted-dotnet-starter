# Project Context

This repository is a .NET 8 backend using Clean Architecture and DDD.

Stack:
- .NET 10
- C# 12
- ASP.NET Core Minimal / Controllers
- MediatR for CQRS
- EF Core 10 with SQL Server
- FluentValidation for input validation
- xUnit for tests
- AutoMapper for mapping between Domain and DTOs

Goals:
- Provide a clean and extensible template for future business domains.
- Focus on maintainability, testability and clear separation of concerns.
